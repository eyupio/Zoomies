# Testsmith's Journal: Zoomies

Critical test-coverage learnings only. Routine test additions are not logged here.

## 2026-09-27 - A helper's one conditional branch went untested across three call sites at once
Learning: `internal/scheduler/resources.go`'s `fieldFactor(p, typed)` returns `2` only when a field is both typed (operator-set, not derived from the host) and the pool runs docker-in-docker, and it is shared by `RunnerCharge`, `MinimumReserve` and `ReducedSize`. Every existing reduced-runner test happened to exercise a case where the condition is false: an automatic (untyped) DinD pool, or a typed non-DinD pool. The one combination that actually returns `2` -- a fixed-size DinD pool's reduced runner -- was placed and its per-container grant was asserted (`TestAReducedDockerInDockerPairSplitsWhatIsLeft`), but nothing fed that grant back through `RunnerCharge`/`Reserved` to check the doubling recovers the original host-side charge.
Risk: This is precisely the bug class the file's own comments describe as having shipped twice already, in both directions (charging one share while giving each container a whole one, and the mirror of it) -- a silent host-accounting drift that only shows up later as create timeouts on a machine the fleet believes is idle, or as a fleet refusing to use machines it has room on. Three functions sharing one helper meant one broken conditional would corrupt scheduling, minimum-reservation and reduced-sizing math simultaneously, and none of it would fail a test.
Action: When a helper's return value depends on a boolean combination (here: typed AND DinD), check that every *combination*, not just every call site, is covered by a test that traces the value through to an externally observable effect -- not just an intermediate value like a placement's per-container grant. Added `TestAReducedDockerInDockerRunnerIsChargedTwiceItsRow`, which places a reduced pair and then asserts `RunnerCharge`/`Reserved` double the row's stored allocation back to the charge. Verified it fails when the doubling condition is forced off.
